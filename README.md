# WorkConnect_SWP
WorkConnect_SWP là nền tảng web hỗ trợ tuyển dụng và tìm việc, cho phép ứng viên tạo và quản lý hồ sơ cá nhân, CV, kinh nghiệm, học vấn, lưu tin tuyển dụng, ứng tuyển và theo dõi lịch phỏng vấn. Hệ thống cũng cung cấp cho nhà tuyển dụng các chức năng đăng tin, quản lý bài đăng, xem hồ sơ ứng viên, quản lý ứng dụng và lịch phỏng vấn; đồng thời cho phép quản trị viên kiểm duyệt nhà tuyển dụng, quản lý công ty, tin tuyển dụng và phản hồi hệ thống. Dự án được xây dựng theo mô hình MVC với Java JSP/Servlet, JDBC/DAO và SQL Server, tập trung vào phân quyền người dùng, quản lý dữ liệu và tối ưu trải nghiệm thao tác trên web.
